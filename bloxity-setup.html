Hosting steps

  1. GitHub: create the empty repo for clackstack (no README) and add the repo secret LEGION_DEPLOY_TOKEN (from hosting.bloxity.io). To ship to stage too, add LEGION_DEPLOY_TOKEN_STAGE (from hosting.stage.bloxity.io).
  2. hosting.bloxity.io (and hosting.stage.bloxity.io for stage): the app clackstack must exist (its id is GAME_ID in .github/workflows/deploy.yml).
  3. Push the code to main: the workflow builds the server image and the client and deploys both, to prod (and stage once its token is set).
  4. After the first run, make the GHCR package clackstack-server public (GitHub → Packages → Package settings → Change visibility), else Legion can't pull it.
  5. Check https://clackstack.host.bloxity.io/health (it should say "db": true) and play at https://clackstack.play.bloxity.io.
  6. Create the game in Manage Games with the values above (slug exactly clackstack).
